# E4 后续候选的解题计划消融

用 Llama-3.1-8B-Instruct 按固定题序双卡运行。每题生成一份共享的前五条 E4 候选。五条提取答案一致且非空时，两组返回相同答案并跳过外层 PRM。其他题把共享候选交给两组，先对共享前缀评分一次。

- A 组按原 E4 规划提示继续生成至多五条。
- B 组在原规划提示末尾追加本题已经尝试的计划，要求换一个求解路线。计划只取前 320 个字符，压缩空白并去重。每生成一条完整候选，就把它的计划纳入该组后续步骤。模型仍使用原来的工具和计算策略选择。
- 两组沿用 [PR #28](https://github.com/zhaqian21/adaptive-ttc-lab/pull/28) 的同答案 Top-2 PRM 求和。每组使用原样复用的五条前缀得分，以及本组实际完成的后续候选得分。

## 后续预算

每组每道续跑题都可用 100,000 个后续生成 token，输入和输出合并计费。历史完整候选中，403 道未早停题的第 6–10 条实测用量 P90 是 93,166。审批每个模型请求时，先为输入和最大输出预留空间，再按响应实际用量计费。给定剩余额度无法容纳完整请求时，结束这个分支，保留已完成的候选并记录部分生成的实际用量。缺失用量的请求按预留上限计入预算。外层 PRM 请求另计。

候选种子按题号、候选位置、重试序号确定。两个后续分支用相同的种子公式，按题号在每卡交替先后顺序。双卡墙钟包含共享前缀和两组后半程。各组的后半程用时另报 P50 和 P95，包含生成及外层 PRM。所有生成与评分使用固定的模型快照、vLLM 0.33.0 和公开 E4 上游代码，硬件沿用 24 服务器两张 H20。

## 指标与进度

沿用 [PR #26](https://github.com/zhaqian21/adaptive-ttc-lab/pull/26) 的 Llama MATH-500 题序和 20 题试跑集。试跑验证两条分支、共享评分和预算记录后，另跑一轮完整 500 题。主要指标是前五条没有正确解、且第 6–10 条首次找到正确解的题数。逐题保留两组选优、共享题的候选指纹、成功与失败调用、是否触及预算、各组耗时和前缀单独用量。

只有 B 组的首次找到正确解题数和最终答对数都严格大于 A，才使用固定的同一套规则运行 Llama AIME24 全部 30 题。AIME24 使用 [PR #20](https://github.com/zhaqian21/adaptive-ttc-lab/pull/20) 的固定数据版本。队列结束后复原常驻生成和 PRM 服务。

20 题试跑通过，6 题在共享前缀处早停。A、B 各答对 15 题，分别有 2 题和 5 题触及后半程预算。试跑首次触及预算时，上游网络重试拦截了预算终止信号。修正后从头重跑了试跑，正式轮随后独立开启。归档包含通过审计的试跑结果。

## MATH-500 正式结果

500 题通过双卡审计。90 题在共享前缀处早停，410 题进入两组后半程。其中 142 题的前五条候选都没有正确解。以下 token、请求和延迟均统计各组后半程。

| 指标 | A 原 E4 规划 | B 规划器参考已尝试路线 |
|---|---:|---:|
| 后续候选首次找到正确解 | 30/142 | 29/142 |
| 候选池含正确解 | 383/500 | 382/500 |
| 最终答对 | 331/500（66.2%） | 326/500（65.2%） |
| 生成模型输入与输出 token | 25,707,631 | 28,760,976 |
| 完整后续候选 | 2,005 | 1,984 |
| 触及后半程预算的题数 | 34 | 52 |
| 外层 PRM 请求 | 2,005 | 1,984 |
| 后半程 P50 | 149.9 秒 | 172.4 秒 |

同一前缀下，B 改对 20 题、改错 25 题。仅 A 首次找到正确解的有 18 题，仅 B 找到的有 17 题，两组都找到的有 12 题。B 后半程生成 token 多 11.9%。共同前缀测得 30,594,528 个生成 token 和 2,050 次外层 PRM 请求，按每组加回共享前缀后，B 生成 token 多 5.4%。整轮双卡耗时 75 分 48 秒。AIME24 的两项收益门槛未达到，服务器在完成 MATH-500 审计后恢复常驻服务。

## 复跑

按 [24 双卡复现](../llama-table1-825/README.md#24-号双卡接续) 准备 `source` 目录与模型、数据和 Python 环境。`OUTPUT` 为独立服务器运行目录，包含验证后的 `source` 和 `assets.exit`。

~~~bash
exp=experiments/e4-diverse-continuations
bash experiments/llama-table1-825/run_24.sh "$OUTPUT" "$VLLM_PYTHON" "$exp/run.py"
python "$exp/audit.py" --root "$OUTPUT/results"
~~~

`audit.py` 核对所有题号、分片、候选与请求顺序、种子、实际预算、规划上下文指纹、逐次 PRM 和 Top-2 选优，并重算对照汇总。归档中每阶段的两份 worker 配置保存为 `gpu-0_config.json` 与 `gpu-1_config.json`。服务器上会按题原子保存检查点，后续只从同一配置恢复。
